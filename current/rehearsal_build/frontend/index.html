    More syntax

    How to use these buttons

    Select words to wrap them, or place the caret and choose a button. Replace the selected placeholder. Insert inside the document body, between \begin{document} and \end{document}. Nothing compiles automatically.

    Example: Bold creates \textbf{Text}. Lists use \item for each item. Tables separate columns with & and end rows with \\. Equations expect math syntax, not ordinary prose.

    Undo syntax insertion reverses up to 12 insertions in this session. Undo later typing first; it will never discard later edits.

    Idle

    Compile sends the saved draft to the local backend (POST /drafts/{id}/compile) and shows only the PDF returned for the current revision. It stays disabled while no LaTeX engine is found on this machine.

    About compiling local LaTeX

    Compile runs in a temporary directory with a cleaned environment and shell escape off. That is not a container and cannot promise a hostile document fails to read another file on this machine. Diagnostics carry severity and line; select one to jump to the line.
