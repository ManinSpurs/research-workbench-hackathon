Hackathon FAQ (as provided by the participant)

This is a participant-provided summary, not an official document. It records only what
the participant wrote down and what the shared FAQ text states. Nothing here is presented
as an organizer's direct quote to the participant.

- A project must meaningfully use the Meta Model API and/or Meta open-weight models.
- According to the official Discord FAQ text the participant shared on 2026-10-31, the four
  criteria are weighted equally (25% each). The repository's earlier records marked the
  weights NOT_STATED, so this line rests on the shared text, not on an earlier record.
  Those four criteria are impact, use of Meta tooling, technical depth and demo quality.
- The submission is due Nov 4 at 9:00 PM ET.
- A submission needs a 3-minute demo video, a public repository and the names of its
  contributors.
